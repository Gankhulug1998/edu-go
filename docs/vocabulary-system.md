# Үгийн сангийн систем (Vocabulary System)

Edu Go-ийн ханзны санг **системтэйгээр** өсгөх бүтэц. Гурван хэмжээс:

## 1. Түвшин (`level`)
| id | slug | Нэр | Тайлбар |
|----|------|-----|---------|
| 1 | `anhan` | Анхан шат | Хамгийн түгээмэл, энгийн 2 хэсэгт ханз |
| 2 | `dund` | Дунд шат | 3 хэсэгт болон арай нарийн нийлмэл ханз |
| 3 | `gunzgii` | Гүнзгий шат | Хийсвэр утга, олон бүрэлдэхүүнт (нөөц) |

## 2. Ангилал (`category`) — нэг карт = нэг үндсэн ангилал
`baigal` Байгаль 🌳 · `xun` Хүн ба гэр бүл 👥 · `biye` Бие 🫀 · `uil` Үйл 🏃 · `setgel` Сэтгэл 💭 · `chanar` Шинж чанар ✨ · `zuils` Зүйл 📦

## 3. Шошго (`tags`) — багц/шүүлтэд, олон байж болно
- `triple` — нэг дүрс 3 дахин (森 众 炎 晶 品)
- `radical:X` — радикал гэр бүл (`radical:水`, `radical:亻`, `radical:艹`, `radical:口`, `radical:心`, `radical:日`, `radical:木` …)
- `hsk1`, `hsk2` … (нэмж болно)

## Багц (`public/packs.json`)
Курацлагдсан, **сурах эрэмбэтэй** ханзны цуглуулга. Талбарууд: `id, title, description, level, category, icon, characters[]`. Нэг ханз олон багцад орж болно (ж: 你 нь *people-basics* ба *person-radical* хоёуланд).

Одоо **12 багц**, **49 ханз** (24 анхан + 25 дунд).

## Цаашид өсгөх журам
1. `scripts/expand-vocab.py` доторх `NEW` жагсаалтад шинэ ханз нэмнэ (`card(...)` туслахаар).
   - **Заавал зөв байх:** задаргаа (parts), пиньин, монгол утга, жишээ үг.
   - Хэсэг бүрд монгол шошго (`label`) өг (ж: 月→сар, 口→ам).
2. `python3 scripts/expand-vocab.py` ажиллуул — idempotent (character-аар upsert).
3. Шинэ ханзыг `public/packs.json` доторх тохирох багцад нэм (эсвэл шинэ багц үүсгэ).
4. `curl -X POST localhost:3000/api/admin/reseed` → DB-д ачаална.
5. Шалгах: `POST /api/drafts/:character/render?noai=1` → рендер зөв эсэх.

## Мэдэгдэж буй цоорхой — Үндсэн дүрс (pictograph) картууд
Одоогийн картууд бүгд **нийлмэл** (A+B=C). Гэвч суурь радикалууд өөрсдөө (木 人 口 日 月 水 火 山 田 女 …) тусдаа карттай болоогүй — учир нь тэдгээр нь задрахгүй, харин **зургийн гарал үүсэл** (象形) -ээр тайлбарлагдана.

**Шийдэгдсэн:** `kind: 'simple'` карт нэмэгдсэн (`src/types.ts`, `src/template.tsx` дахь `SimpleCard`). Задрахгүй ханз (人 日 山 …) "ҮНДСЭН ДҮРС" хэлбэрээр харагдана — A+B=C мөргүй.

## HSK найдвартай pipeline (`scripts/gen-hsk1.py`)

"Алдаа дутагдалгүй" байхын тулд **баримтыг эрх бүхий датасетаас** авна (санах ойноос биш):
- **Пиньин + задаргаа** → makemeahanzi (`data/sources/mmah.txt`)
- **Ханзны багц** → HSK албан жагсаалт (`data/sources/hsk_old_{1,2}.json`)
- **Жишээ үгийн пиньин** → CC-CEDICT (`data/sources/cedict.txt`, дугаар→диакритик хувиргалт скрипт дотор)
- **Монгол утга/шошго/жишээ-орчуулга** → скрипт дотор гараар (хянагдсан)

**Найдвартай байдлын гол дүрэм:** ханз зөвхөн **бүх бүрэлдэхүүн нь `COMPONENT_MN`-д (утга бүхий) байвал** A+B=C болно; үгүй бол `simple`. Ингэснээр утгагүй зураасны хэлтэрхийг (⺈ 丂 乛 …) "утга" гэж буруу шошголохгүй.

**Ажиллуулах:**
1. `bash scripts/download-sources.sh` (эх өгөгдөл татах — `data/` нь git-д ороогүй)
2. `python3 scripts/gen-hsk1.py` (idempotent — байгаа картыг дахин бичихгүй)
3. `curl -X POST localhost:3000/api/admin/reseed`

**Төлөв:** HSK1 = 178 ханз бүрэн (162 шинэ; ~46 compound + ~116 simple). HSK2 (дараагийн ~168) ижил pipeline-аар үргэлжилнэ. Монгол хэллэгийг эх хэлтэн (хэрэглэгч) эцсийн байдлаар хянахыг зөвлөнө.

**Дараагийн алхам:** "pictograph" картыг сайжруулж эртний зураг→орчин үе хувьслыг харуулах; HSK2 үргэлжлүүлэх.
